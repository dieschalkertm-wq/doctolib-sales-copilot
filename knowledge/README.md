## So fütterst du mich (ganz einfach)
Schreib einfach in den Chat, zum Beispiel:

- **„Speichern als Produkt-Update:“** + Text einfügen → ich sortiere es nach `produkt/` und sage dir, was neu ist.
- **„Transkript auswerten:“** + Text → Zusammenfassung, was gut lief, was besser geht, nächste Schritte.
- **„Ich gehe morgen zu Praxis X, die haben PVS Y.“** → ich baue dir einen Termin-Leitfaden.
- **„Mail an …“** + Stichpunkte → Entwurf (auf Wunsch direkt in Gmail als Entwurf).
